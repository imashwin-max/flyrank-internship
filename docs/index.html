Predicting Content Decay: A Machine Learning Approach

By Ashwin Max — ML & Search Intelligence Intern

Abstract

This project builds a machine learning scoring system to identify pages showing strong signals of traffic decline. Using anonymized historical search data from FlyRank, I framed the problem as a scoring and ranking task. The resulting Random Forest model successfully learned non-linear decay patterns, outperforming hardcoded heuristic rules (~88% vs 48% Precision@50).

1. Introduction / Problem Statement

Websites accumulate massive amounts of content, and over time, search performance naturally decays. Editorial teams have limited capacity and must decide: Which existing page should we rewrite or update next to defend our traffic? This project provides a directional, decision-support tool that ranks pages by their likelihood of decay.

2. Methodology

  • Task Definition: Scoring and Ranking via Binary Classification.
  • Target Proxy: Defined a page as "decaying" if its observed trend was negative.
  • Features: content_age_days, impressions_90d, avg_position, ctr.
  • Model: Random Forest Classifier to capture non-linear relationships.
